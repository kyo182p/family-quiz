# 家庭題庫練習（GitHub Pages 版）

## 考卷分析

家長上傳塗黑個資的考卷，逐題確認 AI 判讀，再以挑戰比較結果並查看孩子各科紀錄。

本功能由家庭題庫站長（網站維護者）經營。考卷照片會送到美國的 Anthropic 處理（境外傳輸），用來辨識題目；Anthropic 不拿來訓練 AI，約 30 天內刪除。告知內容改版時（目前第 3 版），家長要重新看過並按同意，舊的同意會失效。

新建一份 Google 試算表作為資料表，將其 ID 放入 Apps Script 的 Script Properties `DIAG_SHEET_ID`。把 `Code.gs` 貼回 Apps Script 後執行一次 `setupDiag`，建立五張資料表與每日觸發器 `diag_retentionDaily`，資料保存 12 個月。`ANTHROPIC_API_KEY` 沿用原有設定。

考卷每頁扣 1 次、出一份挑戰扣 1 次；失敗與家長修改不扣次數，與原本每天 10 次的額度共用。照片不保存，上傳前請塗黑姓名、學校、班級、座號、分數等個資。

這次更新（第 3 輪）要手動做的事：

1. 把新的 `Code.gs` 貼回 Apps Script 並重新部署（新增孩子裝置鑰匙的路由）。
2. 家長打開「考卷分析」，重新看過告知並按「同意，開始」（告知改版，舊的同意失效）。
3. 在每個孩子平常用的裝置上，家長登入家長頁 →「考卷分析」→「孩子的裝置」→ 按一次「讓這台裝置給（暱稱）用」。每個孩子同時只有一台裝置有效，換裝置要再按一次；不用了可以按「停用（暱稱）的裝置」。沒按過的裝置，孩子首頁會顯示「請家長在這台裝置開啟練習」，一般練習不受影響。

本機試用：執行 `npm run build`，開啟 `dist/index.html`（假後端），家長設定碼為 `MOCK2345`。可用 `?mock=diag-fail2`（第二頁失敗）、`?mock=diag-zero`（沒有讀到題目）、`?mock=diag-name`（個資過濾）或 `?mock=offline`（斷線）試用狀態畫面。 假的孩子裝置鑰匙：用 MOCK2345 登入家長頁 →「考卷分析」→「孩子的裝置」→ 按「讓這台裝置給 小葉子 用」。

課綱出處：國家教育研究院《十二年國民基本教育課程綱要》[數學領域](https://www.naer.edu.tw/upload/1/16/doc/815/十二年國民基本教育課程綱要國民中小學暨普通型高級中等學校-數學領域.pdf)、[英語文（附錄五）](https://www.naer.edu.tw/upload/1/16/doc/812/\(發布版\)國民中小學暨普通型高級中等學校-語文領域-英語文課程綱要.pdf)。本站為個人非營利使用，不代表該院立場。

這是植物小學堂的獨立開發版本，和目前 claude.ai 上的網頁版互不影響。

- 前端：`index.html`，放在 GitHub Pages，任何人打開網址就能練習，不需要 Claude 帳號
- 後端：`apps-script/Code.gs`，綁在一份 Google 試算表上，負責：
  - 驗證「家庭邀請碼」、控管每天的 AI 次數
  - 代替網頁呼叫 Claude API（API 金鑰只存在後端，網頁看不到）
  - 把各家庭的題庫存在試算表
  - 記錄每次 AI 呼叫的 token 數與估計費用

## 二、設定步驟

### 步驟 1：申請 Claude API 金鑰

1. 到 platform.claude.com 註冊或登入。
2. Settings → Billing → Buy credits，儲值 5～10 美元。自動儲值先保持關閉。
3. Settings → API Keys → Create Key，複製金鑰（`sk-ant-` 開頭）。**金鑰只會顯示一次**，先貼到安全的地方。

### 步驟 2：建立 Google 試算表與 Apps Script

1. 在 Google 雲端硬碟新增一份試算表，名稱例如「家庭題庫後端」。
2. 選單「擴充功能 → Apps Script」。
3. 把 `apps-script/Code.gs` 的內容整個貼上，取代原本的程式，儲存。
4. 上方函式選單選 `setup`，按「執行」。第一次會要求授權，依畫面允許。
   - 執行完試算表會多出四個工作表：家庭、題庫、題目、用量。
   - 「家庭」工作表會有一列測試用的 `TEST-0000`。
5. 左側「專案設定（齒輪）」→ 最下面「指令碼屬性」→ 新增：
   - 屬性：`ANTHROPIC_API_KEY`
   - 值：步驟 1 複製的金鑰
6. 右上「部署 → 新增部署作業」：
   - 類型：網頁應用程式
   - 執行身分：我
   - 誰可以存取：所有人
   - 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
7. （建議）左側「觸發條件」→ 新增：函式 `cleanupCounters`、時間驅動、每天一次，用來清掉前幾天的次數計數。

### 步驟 3：設定家庭邀請碼

在「家庭」工作表每個家庭一列：

| 邀請碼 | 家庭名稱 | 每日 AI 上限 | 啟用 | 備註 |
|---|---|---|---|---|
| FAMILY-A001 | 甲家 | 10 | TRUE | |
| FAMILY-B002 | 乙家 | 10 | TRUE | |

- 要暫停某個家庭：把「啟用」改成 FALSE。
- 測試完可以刪掉 `TEST-0000`。

### 步驟 4：把後端網址填進網頁

打開 `index.html`，找到這一行（在 `<script>` 裡，搜尋 `CONFIG`）：

```js
const CONFIG={API_URL:''};
```

改成步驟 2 複製的網址：

```js
const CONFIG={API_URL:'https://script.google.com/macros/s/xxxx/exec'};
```

### 步驟 5：發布到 GitHub Pages

1. 在 GitHub 建一個新的 repo，例如 `family-quiz`，設為 Public。
2. 上傳 `index.html` 到 repo 根目錄。
3. Settings → Pages → Build and deployment：
   - Source：Deploy from a branch
   - Branch：`main`、資料夾 `/ (root)` → Save
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/family-quiz/`。

### 步驟 6：測試

1. 打開網址，右上角「🧪 自訂題庫」→「⚙️ 家庭設定」→ 輸入 `TEST-0000` → 驗證。
2. 建立一個題庫 → 上傳資料 → 貼一段文字或放一張講義照片 → 開始分析。
3. 回到試算表確認：
   - 「題庫」有一列資料
   - 「題目」可以看到每一題
   - 「用量」記錄了這次的 token 數和估計美元
4. 到 Console 的 Usage 頁面，確認實際扣款和「用量」工作表差不多。

## 三、之後修改程式

- **改 `index.html`**：重新上傳到 GitHub，幾分鐘後生效。
- **改 `Code.gs`**：Apps Script 裡「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」。這樣網址不變，不用改 `index.html`。

## 五、題庫書架與親友閱讀碼（新增）

### 第一次升級要做的事

1. 把新版 `Code.gs` 整個貼上取代舊的，儲存。
2. 函式選單選 `setup` 執行一次，會：
   - 在「家庭」工作表加上第 F 欄「可發布」
   - 新增「閱讀碼」和「公開題庫」兩個工作表
3. 「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」。網址不變。
4. 在「家庭」工作表，把你自己那一列的「可發布」填 TRUE，其他家庭填 FALSE 或留空。
5. 上傳新版 `index.html` 到 GitHub。

### 三種身分

| 身分 | 可以做的事 |
|---|---|
| 沒有代碼 | 只能練習內建的植物小學堂 |
| 親友閱讀碼 | 練習題庫書架上所有公開題庫；作答紀錄只存在自己的裝置；不能用 AI |
| 家庭邀請碼 | 上面全部，加上用 AI 建立自己的題庫、產生親友閱讀碼 |
| 邀請碼＋可發布 | 上面全部，加上把自己的題庫公開到題庫書架 |

### 工作表說明

- **閱讀碼**：每一組閱讀碼一列，記錄是哪個邀請碼（家庭）產生的、給誰用、建立時間、最後使用時間、使用次數。
  - 每個家庭最多 2 組有效閱讀碼（`Code.gs` 的 `READER_LIMIT`）。
  - 要停用某組：把「啟用」改成 FALSE。
  - 產生閱讀碼的家庭被停用時，它產生的閱讀碼也會一起失效。
- **公開題庫**：目前公開在題庫書架上的題庫。刪掉一列就等於取消公開。
  - 書架清單有 10 分鐘快取，直接改工作表後最多 10 分鐘才會反映。

### 注意

- 公開題庫只提供題目、觀念和詳細解題，不會提供你的作答紀錄、待確認題目和學習摘要。
- 公開題庫裡有講義原題，請只把閱讀碼給親友，不要公開張貼。

## 六、題目回報、獎勵與定期掃題（新增）

### 升級步驟

1. 新版 `Code.gs` 整個貼上取代舊的，儲存。
2. 執行一次 `setup`，會：
   - 新增「回報」工作表
   - 「家庭」工作表加上第 G 欄「獎勵 AI 次數」
   - 「題目」工作表加上「題目ID、判讀狀態、判讀意見、判讀時間、回報」欄位
   - 在指令碼屬性產生 `ADMIN_TOKEN`（定期掃題用的管理者金鑰，不要外流）
3. 部署 → 管理部署作業 → 編輯 → 新版本 → 部署。
4. 上傳新版 `index.html`。

### 回報規則

- 有閱讀碼或邀請碼的人，練習時可以按題目旁的「🚩」回報。
- 同一題已經有人回報（待複審或成立）就不能再回報，題目上會顯示「已有人回報，確認中」。
- 每組代碼每天最多回報 10 題（`REPORT_DAILY_LIMIT`）。
- 回報由定期掃題的 AI 判定成立或不成立，不需要人工確認。
- 回報成立：
  - 題目暫停出題，直到題目被修改
  - 邀請碼家庭獲得 3 次 AI 使用次數（`REWARD_PER_REPORT`），同一題只發給第一位；閱讀碼不適用
- 獎勵次數在每日上限用完後才會扣，記在「家庭」工作表 G 欄，可以手動調整。
- 題目被修改後：AI 判讀會清除、等下次重新判讀；原本成立的回報會標成「已修正」。

### 定期掃題

- 用 Claude 的排程工作執行，使用 Max 方案的模型額度，不使用 API Key。
- 指示內容在 `scanner/SCAN_PROMPT.md`。
- 排程的執行環境需要能連到 `script.google.com` 和 `script.googleusercontent.com`。
- 判讀結果寫在題目資料裡，並同步顯示在「題目」工作表；判定有問題的題目會暫停出題，「題目清單」頁可以一鍵帶入 AI 建議的修正。

## 七、重點講義（新增）

### 升級步驟

1. 新版 `Code.gs` 整個貼上取代舊的，儲存。
2. 執行一次 `setup`，會新增「講義」工作表。
3. 部署 → 管理部署作業 → 編輯 → 新版本 → 部署。
4. 上傳新版 `index.html`。

### 說明

- 入口：題庫首頁「大人使用」區塊的「📘 重點講義」，以及練完一輪的結果頁。
- 觀念可以複選：答錯過的觀念排前面並預設勾選，也可以全選做整個題庫的講義。
- 選多個觀念時，AI 先診斷「這些題目答錯的共同原因」，把觀念歸成 1～4 個根本觀念，每個根本觀念寫一段，練習題混著出、加入容易搞混的比較題。
- AI 次數：單一觀念 3 次；多個觀念為「1 次診斷＋根本觀念數＋2」。在背景進行，完成後左下角會提示，中斷可以接著產生。
- 練習時會記錄孩子答錯時選了哪個答案，診斷時一起參考。
- 一～四年級的題庫產生「簡單版」：沒有卡題索引，每段是標題、為什麼會錯、圖（內建插圖或圖卡）、記住、試試看、小心，字數少、句子短；練習 7 題，答案只寫一行。五、六年級維持完整版。
- 講義存在「講義」工作表（一份一列，JSON 分段放在 K 欄之後），狀態為「待驗算」。
- 定期掃題會逐題驗算（數學用 Python），寫回「已驗算」或「已修正」。
- 公開到題庫書架的題庫，有閱讀碼的親友也能看講義，但不能產生。
- 列印：講義頁的「🖨 列印／存成 PDF」，A4、框不跨頁；頁尾頁碼在 Chrome 會顯示，Safari 可能不顯示。

## 八、出題驗算、答錯提示、學習徽章

- 出題驗算：AI 產生題目後，另一次 AI（Sonnet）不看答案獨立作答；答案對不上或題目不清楚的，移到「待確認的題目」並標 🔍 原因。只驗算 AI 判斷答案的題目（AI 新題、改寫題、講義沒附答案的題目）。每 40 題多用 1 次 AI。
- 答錯先給提示：選擇題（3 個以上選項）第一次答錯，劃掉選錯的選項並顯示提示，可以再選一次；紀錄仍算答錯一次。提示用題目的 hint（新產生的題目會有），沒有就用這題的觀念。
- 學習徽章：每個題庫自動產生一枚立體琺瑯風格的徽章（程式繪製，不用 AI）。圖案依科目與年級（七個科目×一到六年級，共 42 種原創圖案），主色依單元，右下角小圓牌標羅馬數字單元。第一次就答對揭開幾格，大約答對 15 題全部揭開得到徽章，收進「🏅 我的徽章」（我的題庫的徽章跟作答紀錄一起存在雲端，換裝置看得到；書架題庫與植物小學堂的徽章存在這台裝置）。一般是銀色金屬；收集期間標準、挑戰題答對過半，得到金色金屬加深色琺瑯的進階徽章。得到後可以再收集一輪。
- 開始練習時會先顯示這次要做幾題。首頁有「🎲 幫我選 5 題」。

---

- **看過提示不算徽章**：選擇題第一次答錯會給提示再選一次；靠提示答對的題目不會揭開徽章格子，也不計入金色徽章，畫面會告訴孩子「下次一次答對就算」。
- **列印練習卷**：題庫頁「大人使用 → 🖨 列印練習卷」。可選範圍（全部／答錯過的題）、難度、題數，排成 A4 考卷（是非在前、選擇在後），最後一頁是答案卷，可勾選附解說。**卷號相同就是同一份卷**（題目與選項順序固定），按「換一份」得到新的一份。不需要 AI、不花額度。

- **注音（一、二年級題庫）**：題庫的年級是一年級或二年級時，題目、選項、解說會自動加注音（字的上方），練習中按「ㄅ」可開關，列印練習卷也可以勾選加注音。讀音由 pinyin-pro（從 jsDelivr 載入，只有一、二年級題庫才會下載）判斷，再用 `zhuyin-tw.txt`（台灣讀音差異表，資料來自教育部《重編國語辭典修訂本》，CC BY-ND 3.0 臺灣，經 g0v 萌典與 tjsky/pinyin-annotator 整理）改成台灣讀音。**破音字一定會有判斷錯的**，請到「大人使用 → ㄅ 注音校對」逐題看過：有虛線的是破音字，按一下就能改；改過的讀音存在題庫裡，換裝置也在。`zhuyin-tw.txt` 要和 `index.html` 放在同一個資料夾。

- **徽章跨裝置**：自己的題庫的徽章存在題庫裡；題庫書架和植物小學堂的徽章用家庭邀請碼（或閱讀碼）存在試算表的「徽章」工作表，開站時和打開「我的徽章」時會和雲端合併，換裝置用同一組代碼就看得到。兩台裝置都有紀錄時，得到過的次數會合併，不會互相蓋掉。

- **數學換數字題**：數學題庫在「產生更多題目 → 🔢 數學換數字題」。AI 只寫題型模板（變數範圍、條件、題目、答案與錯誤選項的算式），數字和答案都由瀏覽器裡的程式算，所以答案不會算錯；每次練習換一組數字，列印練習卷換卷號數字也跟著換。程式會先把每個模板試做 200 次，數字不乾淨、變化少於 5 種的模板自動丟掉；再抽一組數字請另一次 AI 驗算題意，對不上的放到待確認。錯誤選項依孩子常犯的錯設計（例如忘了退位、乘除弄反）。算式只支援四則運算、比較和少數函式，不會執行任何程式碼。

- **國語閱讀測驗**：國語題庫（三年級以上）在「產生更多題目 → 📖 閱讀測驗」。AI 依年級寫原創短文（三年級約 350～500 字、四年級 450～650、五年級 600～850、六年級 750～1000），每篇配 5～6 題，每一題都指定 PIRLS 提問層次（依 PIRLS 2021 比例調整：三年級 提取2／推論2／詮釋1；四年級 1／2／1／評估1，評估只考找支持理由；五、六年級 1／2／2／1，可考事實與意見）。文體「混合」時以說明文為主、搭配故事；議論文只有五、六年級可選。每題要附上文章裡的依據句，程式檢查找不到就丟掉，正確答案特別長的放待確認；再做兩次 AI 檢查：看文章驗算答案、不看文章作答（有把握答對表示只考到常識，放待確認）。孩子答完後，文章裡會標出答案的依據句。練習時文章顯示在題目上方，可收合、可朗讀；列印練習卷時文章印在題目前面。

- **上傳試卷檔（PDF、Word）**：上傳頁可以直接選下載的考卷（.pdf、.docx；舊版 .doc 請另存）。PDF 在瀏覽器裡用 pdf.js 讀出文字（最多 20 頁），一份考卷通常 1 次 AI 使用次數、一次最多整理 40 題，並對回卷末的參考答案；掃描的 PDF 自動改成逐頁圖片，題目有圖表時也可以手動「改用圖片讀」（每 2 頁 1 次）。Word 用 mammoth 讀出文字。pdf.js、mammoth 只有選了檔案才會從 jsDelivr 載入。

- **出題風格比照段考**：分析 9 份國小段考卷後調整 AI 出題規則：題幹用中性短句（一般 12～30 字、應用題 30～50 字）、常見人名；每個錯誤選項對應一種具體的錯誤想法；比較題只給 2～3 個選項；自然科約三成反向題；換數字題刻意安排退位、商中間有 0、餘數進位、估算等難點並以兩步以上為主；數字選項由小到大排；閱讀測驗四年級 400～550 字、五年級 450～700 字。原題照抄時不改。

## 家長權限與獎勵(新增)

家長可設定 PIN、管理玩家與獎項，並核准孩子用徽章申請的獎勵。入口是網站的 `#parent`；一般徽章算銀、進階徽章算金，每位玩家分開計算。

既有試算表的升級步驟請依照[家長權限與獎勵部署說明](docs/DEPLOY-reward.md)。本機使用 `npm install` 安裝開發相依套件，`npm run build` 產生 `dist/index.html` 假後端示範，`node --test` 執行自動測試。雲端瀏覽器測試用 npm run e2e，它會自己起本機 http 伺服器並在跑完後關閉，不要用 file:// 開。

## 九、安全與限制

- API 金鑰只存在 Apps Script 的指令碼屬性，網頁原始碼裡沒有。
- 邀請碼等於密碼：拿到邀請碼的人可以讀寫該家庭的題庫、使用 AI 次數。外流時把「啟用」改成 FALSE，再發新的。
- 「題目」工作表是方便查看用的，在這裡修改不會回寫到網站；以「題庫」工作表的 JSON 為準。
- 植物小學堂內建題目寫在 `index.html` 裡；在植物小學堂「用 AI 產生新題目」收進的題目，目前仍只存在該裝置。
- 練習、間隔複習、朗讀都不使用 AI，不會產生費用。
